# Naveen Prasad — 3D Data Analyst Portfolio

A futuristic, responsive portfolio built with HTML, CSS and lightweight JavaScript. The 3D cube, orbital rings, starfield, scroll reveals and hover effects are CSS/canvas based; no build tools are required.

## Deploy
Upload `index.html`, `README.md`, and the complete `assets` folder to the root of your GitHub Pages repository (`Naveendevrari1.github.io`). Keep the certificate PDF at:

`assets/tata-genai-data-analytics-certificate.pdf`

Then commit the changes to `main` and ensure GitHub Pages is set to deploy from `main` / `(root)`.
